## Re-download

To regenerate any image, run:

```powershell
Invoke-WebRequest -Uri "https://images.unsplash.com/photo-<PHOTO_ID>?w=1600&h=900&q=80&auto=format&fit=crop" -OutFile "<local-path>"
```

Hero images use `w=1600&h=900`; listing images use `w=1200&h=800`.
