BLAZOR INTEGRATION NOTES:
1. disabled="@isLoading" — siempre deshabilitar durante la operación.
2. aria-busy="@isLoading.ToString().ToLower()" — para lectores de pantalla.
3. aria-label bilingüe distinto en loading vs default para contexto completo.
4. min-height: 44px — WCAG 2.1 AA touch target size.
5. No usar solo color para indicar estado — el spinner + texto dan señal adicional.
